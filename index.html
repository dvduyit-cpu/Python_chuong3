1. IF / ELIF / ELSE – RA QUYẾT ĐỊNH

1.1. Bản chất

if dùng khi chương trình cần lựa chọn hành động dựa trên một điều kiện đúng hoặc sai. Có thể hiểu như câu nói đời thường: Nếu trời mưa thì mang áo mưa, ngược lại thì không cần.

1.2. Khi nào nên dùng?

  • Kiểm tra điểm đạt/chưa đạt.
  • Kiểm tra số chẵn/lẻ, dương/âm.
  • Kiểm tra tuổi, mật khẩu, điều kiện đăng nhập.
  • Xếp loại theo nhiều mức.

1.3. Chọn cấu trúc nào?

Tình huốngCấu trúc
Chỉ cần làm gì đó khi điều kiện đúngif
Có đúng 2 hướng xử lýif ... else
Có từ 3 trường hợp trở lênif ... elif ... else

1.4. Điều quan trọng nhất: điều kiện phải trả về True/False

age = 18
print(age >= 18)        # True
print(age < 18)         # False
print(age == 18)        # True
print(age != 20)        # True
Lỗi thường gặp: dùng = thay cho ==; quên dấu :; thụt lề sai; đặt điều kiện sai thứ tự.

2. VÒNG LẶP FOR VÀ RANGE()

2.1. Khi nào dùng for?

Dùng for khi biết trước số lần lặp hoặc có một tập dữ liệu cần xử lý từng phần tử.

  • In từ 1 đến 100.
  • Tính tổng 1 đến n.
  • Duyệt danh sách điểm.
  • In bảng cửu chương.

2.2. Cú pháp

for biến_lặp in dữ_liệu:
    khối_lệnh

2.3. range()

Cú phápÝ nghĩa
range(5)0, 1, 2, 3, 4
range(1, 6)1, 2, 3, 4, 5
range(2, 11, 2)2, 4, 6, 8, 10
range(10, 0, -1)10 xuống 1
Dễ nhớ: range không lấy giá trị stop.

# Biến total dùng để cộng dồn, ban đầu bằng 0

3. VÒNG LẶP WHILE

3.1. Khi nào nên dùng?

Dùng while khi chưa biết trước phải lặp bao nhiêu lần nhưng biết điều kiện dừng.

  • Nhập lại đến khi hợp lệ.
  • Đăng nhập đến khi đúng.
  • Menu chạy đến khi chọn thoát.

3.2. Ba thứ phải có

  1. Giá trị ban đầu.
  2. Điều kiện lặp.
  3. Cập nhật để tiến gần điều kiện dừng.
i = 1
while i <= 5:
    print(i)
    i += 1
Vòng lặp vô hạn: nếu điều kiện luôn True mà không có cập nhật hoặc break, chương trình sẽ không tự dừng.

6. COMPREHENSION – VIẾT MÃ NGẮN GỌN

6.1. List comprehension

Dùng khi muốn tạo list mới bằng một phép biến đổi/lọc đơn giản.

squares = [i ** 2 for i in range(1, 6)]
even_numbers = [i for i in range(1, 11) if i % 2 == 0]

6.2. Dict comprehension

square_dict = {i: i ** 2 for i in range(1, 6)}

6.3. Set comprehension

unique_squares = {n ** 2 for n in [1, 2, 2, 3]}
Không nên lạm dụng: nếu biểu thức dài, nhiều if hoặc khó đọc, hãy quay lại vòng for thông thường.

7. GENERATOR EXPRESSION CƠ BẢN

Generator expression giống list comprehension nhưng dùng (). Nó sinh từng giá trị khi cần thay vì giữ toàn bộ dữ liệu trong bộ nhớ.

squares = (i ** 2 for i in range(1, 6))

for value in squares:
    print(value)

Khi nào nên dùng?

  • Dữ liệu lớn.
  • Chỉ cần duyệt một lần.
  • Truyền trực tiếp vào hàm như sum(), max().

Khi nào chưa cần dùng?

Với bài nhỏ cho người mới học, list dễ quan sát và dễ debug hơn.

# tonghop_01_quan_ly_diem.py
scores = [7.5, 4.0, 8.0, 6.5, 3.5, 9.0]

total = 0
passed_count = 0
max_score = scores[0]

for score in scores:
    total += score

    if score >= 5:
        passed_count += 1

    if score > max_score:
        max_score = score

average = total / len(scores)
passed_scores = [score for score in scores if score >= 5]

print(f"Điểm trung bình: {average:.2f}")
print("Số điểm đạt:", passed_count)
print("Điểm cao nhất:", max_score)
print("Điểm đạt:", passed_scores)

# tonghop_02_menu.py
while True:
    print("\n1. Cộng")
    print("2. Trừ")
    print("3. Nhân")
    print("4. Chia")
    print("0. Thoát")

    choice = input("Chọn: ")

    if choice == "0":
        print("Kết thúc chương trình.")
        break

    if choice not in ["1", "2", "3", "4"]:
        print("Lựa chọn không hợp lệ.")
        continue

    a = float(input("Nhập a: "))
    b = float(input("Nhập b: "))

    if choice == "1":
        print("Kết quả:", a + b)
    elif choice == "2":
        print("Kết quả:", a - b)
    elif choice == "3":
        print("Kết quả:", a * b)
    elif choice == "4":
        if b == 0:
            print("Không thể chia cho 0")
        else:
            print("Kết quả:", a / b)
